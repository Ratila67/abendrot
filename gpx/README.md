# Traces GPX

Dépose ici un fichier par rando, puis renseigne son nom dans `data/hikes.json` :

```json
{ "id": "donon", "gpx": "donon.gpx", ... }
```

Les traces déposées ici sont partagées (dans le dépôt). Pour une trace perso, utilise plutôt
le bouton « Importer une trace GPX » dans la fiche : elle reste stockée sur ton téléphone (IndexedDB).
Priorité : trace importée > fichier de ce dossier > tracé schématique.
